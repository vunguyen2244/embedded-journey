## Learning Environment

- MCU: STM32F103C8T6 (Blue Pill)
- IDE: STM32CubeIDE
- Language: C
- Compiler: GCC
- Debugger: ST-LINK
- Operating System: Windows

## Learning Goals

- Strengthen C programming fundamentals.
- Understand pointers, structures, and memory management.
- Learn Embedded C programming.
- Practice STM32 peripherals and debugging.
